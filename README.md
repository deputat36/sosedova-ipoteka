# Соседова Ипотека

Сайт ипотечного брокера Людмилы Соседовой.

Проект создаётся на основе шаблона сайта ипотечного брокера `deputat36/broker`, но развивается отдельно и не изменяет исходный проект.

## Цель проекта

Лидогенерирующий сайт для привлечения клиентов по направлениям:

- подбор ипотеки;
- семейная ипотека;
- сельская ипотека;
- ипотека на строительство дома;
- сопровождение сделок;
- страхование.

## Позиционирование

Людмила Соседова — ипотечный брокер с опытом более 15 лет.

Работа с клиентами из Балашова, Саратовской области и дистанционно по России.

## Статус

Этап разработки: подготовка отдельной версии сайта на базе существующего шаблона.
