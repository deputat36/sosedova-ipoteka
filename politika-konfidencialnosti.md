      <h2>1. Общие положения</h2>
      <p>Настоящая страница описывает базовый подход к обработке данных на сайте «Соседова Ипотека». До запуска полноценной серверной формы обращения сайт не сохраняет содержимое формы подготовки сообщения на собственном сервере.</p>

      <h2>2. Какие данные пользователь может вводить</h2>
      <p>На странице контактов можно указать имя, город, телефон, тип задачи и краткий комментарий. Эти данные используются браузером только для формирования текста заявки, который пользователь затем самостоятельно копирует и отправляет выбранным каналом связи.</p>

      <h2>3. Что не следует отправлять через открытую форму</h2>
      <p>Не передавайте через сайт паспортные данные, СНИЛС, сведения банковских карт, логины, пароли, коды подтверждения, фотографии документов или иные чувствительные данные, пока отдельно не согласован безопасный способ передачи.</p>

      <h2>4. Переходы на сторонние сервисы</h2>
      <p>Сайт содержит ссылки на телефонную связь и ВКонтакте. При переходе на сторонний сервис дальнейшая обработка данных регулируется правилами соответствующего сервиса.</p>

      <h2>5. Технические данные</h2>
      <p>При размещении сайта на хостинге технический провайдер может автоматически обрабатывать стандартные сетевые данные, необходимые для доставки страницы и обеспечения безопасности. Аналитические системы будут подключаться отдельно и только после настройки соответствующих уведомлений и параметров.</p>

      <h2>6. Изменения политики</h2>
      <p>После подключения полноценной формы заявок, аналитики, CRM или иных интеграций политика будет дополнена до запуска таких функций.</p>
