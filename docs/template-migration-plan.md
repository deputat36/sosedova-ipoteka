# План переноса шаблона broker

## Цель

Перенести проверенную основу сайта ипотечного брокера в отдельный проект Соседова Ипотека без изменения исходного проекта Татьяны Стерликовой.

## Этапы

1. Перенос технической основы:
   - layouts;
   - includes;
   - assets;
   - JavaScript;
   - CSS;
   - workflow сборки.

2. Замена жестко заданных данных:
   - имя брокера;
   - контакты;
   - изображения;
   - тексты;
   - SEO.

3. Подключение конфигурационного слоя:
   - _data/broker.yml;
   - _data/services.yml;
   - _data/seo.yml.

4. Подготовка уникального позиционирования Людмилы Соседовой.

## Ограничения

Исходный репозиторий broker не изменяется.

Все доработки выполняются только в sosedova-ipoteka.
