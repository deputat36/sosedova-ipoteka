# План разработки сайта «Соседова Ипотека»

## Цель

Создать полноценный лидогенерирующий сайт ипотечного брокера, а не визитку.

## Основа

Проект создаётся отдельно от `deputat36/broker`.

Исходный сайт Стерликовой используется только как техническая и структурная база.

## Этапы

1. Подготовка отдельного проекта.
2. Выделение конфигурации брокера.
3. Адаптация бренда и контента.
4. Создание SEO-страниц услуг.
5. Настройка заявок и аналитики.
6. Подготовка к запуску.

## Важный принцип

Данные брокера, SEO и контент должны быть отделены от технического шаблона для возможности создания новых сайтов.
