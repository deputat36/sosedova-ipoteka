# Контент-план сайта Соседова Ипотека

## Главная цель
Создать сайт, который привлекает заявки через поиск, рекламу и рекомендации.

## Приоритетные направления

1. Ипотека для семей с детьми
2. Сельская ипотека
3. Ипотека на строительство дома
4. Помощь после отказа банка
5. Подбор ипотечной программы
6. Страхование как дополнительная услуга

## Следующие блоки сайта

- преимущества брокера;
- отзывы клиентов;
- реальные кейсы;
- ответы на частые вопросы;
- полезные статьи;
- формы заявки.

## Важно
Все фактические цифры, стоимость услуг и гарантии добавляются только после подтверждения со стороны Людмилы Соседовой.
